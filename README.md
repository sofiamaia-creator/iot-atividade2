## Enunciado: Controle de Miscroservo com Potenciômetro

O projeto vai integrar dispositivos de entrada e saída para realizar ações de controle. Nesta atividade, utilizando o Tinkercad, é necessário integrar um potenciômetro e um microservo ao Arduino, utilizando a leitura da entrada para controlar a posição do atuador.


## Materiais necessários

| Qtd | Componente |
|-----|------------|
| 1 | Placa Arduino UNO |
| 1 | Cabo USB |
| 1 | Protoboard |
| 1 | Micro servo |
| 1 | Potenciômetro |
| — | Fios de jumper macho-macho |
